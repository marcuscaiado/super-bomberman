# 💣 Super Bomberman (SNES)

Authentic *Super Bomberman* running online at 60 FPS in WebAssembly via EmulatorJS.

## 🕹️ Live Play
- **Play Online**: [https://marcuscaiado.github.io/super-bomberman/](https://marcuscaiado.github.io/super-bomberman/)
- **Arcade Hub 3D**: [https://marcuscaiado.github.io/nopex-arcade/](https://marcuscaiado.github.io/nopex-arcade/)
- **Arcade Catalog 2D**: [https://marcuscaiado.github.io/marcus-arcade/](https://marcuscaiado.github.io/marcus-arcade/)

## 🎮 Controls
- **D-Pad / Movement**: Arrow Keys or Mobile Touch D-Pad
- **Drop Bomb**: Z (SNES B)
- **Detonate Remote / Special**: X (SNES Y)
- **Kick Bomb**: A (SNES A)
- **Pause**: Enter (Start)
- **Gamepad**: Native USB & Bluetooth Gamepad supported
